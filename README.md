## Before publishing
1. Put your resume PDF in this folder as `resume.pdf`.
2. Replace `YOUR_EMAIL@example.com` with your actual email in `index.html` and `script.js`.
3. Replace the LinkedIn placeholder URL with your actual LinkedIn profile URL.
4. Replace project `#` links in `script.js` with the actual GitHub/live-demo URLs.
5. Open `index.html` or deploy the folder on GitHub Pages, Netlify, Vercel, or Replit.

The contact form currently opens the visitor's email app using mailto. For server-side form submission, connect a secure backend/form service.
